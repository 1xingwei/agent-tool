# 使用 Google 模型

Google 提供两种访问其模型的方式，二者适用不同的服务条款与使用政策。

推荐使用哪一种超出了本文档的范围，但确实有差异需要考虑。

两种方式是：

1. Gemini Developer API [文档链接](https://ai.google.dev/gemini-api/docs)
2. Google Cloud Platform 上的 Google Vertex AI [文档链接](https://cloud.google.com/vertex-ai/docs)

## 使用 Gemini Developer API

[从 Google 获取 Gemini API Key](https://ai.google.dev/gemini-api/docs)，即可在 Agent Service Toolkit 中快速用起来。

1. 把 API Key 填入 `.env` 文件中的 `GOOGLE_API_KEY` 环境变量
2. Agent Service Toolkit 会自动读取该凭证，无需其他操作

## 使用 Google Cloud Platform 上的 Google Vertex AI

### 前置条件

确保你有一个 [Google Cloud 项目](https://console.cloud.google.com/projectcreate)，且已[开通结算](https://console.cloud.google.com/billing)。

### 关于鉴权

要以编程方式使用 Vertex AI，你需要创建一个**服务账号（service account）**，并用其凭证为应用做身份认证。这些凭证与你的个人 Google 账号凭证不同，它决定了你的应用能访问哪些 Google Cloud 服务与 API。

Vertex 使用基于 JSON 的凭证文件，并在运行时读取 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量来获取该文件的路径。

### 模型

Vertex AI 同时包含**稳定版**和**实验/预览版**模型。实验版与预览版模型可能在不通知的情况下变更或下线，因此**生产应用**强烈建议使用稳定版模型。最新的模型状态请查阅 [Vertex AI 文档](https://cloud.google.com/vertex-ai/docs)。

### 步骤

#### 1. 启用 Vertex AI API

- 打开 [Google Cloud API Library](https://console.cloud.google.com/apis/library)。
- 在顶部下拉框中选择你的项目。
- 搜索 "Vertex AI API" 并点击 **Enable**。

#### 2. 创建并配置服务账号

- 进入[凭证页面](https://console.cloud.google.com/apis/credentials)。
- 点击 **Create Credentials** > **Service Account**。
- 填写详细信息（例如名称与描述）。
- **分配角色**：对 Vertex AI 而言，至少授予 "Vertex AI User" 角色。
- 点击 **Done**，然后找到你的服务账号，点击三点菜单（⋮），选择 **Manage Keys**。
- 点击 **Add Key** > **Create New Key**，选择 **JSON**，然后点击 **Create**。
- JSON 密钥文件会开始下载。**请妥善保存**——这个文件无法再次下载。

#### 3. 把 JSON 密钥文件放入[基于文件的凭证](05-基于文件的凭证管理.md)目录

把下载的 JSON 文件放进项目的 `privatecredentials/` 目录（例如 `privatecredentials/service-account-key.json`）。

[基于文件的凭证](05-基于文件的凭证管理.md)目录中的内容会在运行时以 `/privatecredentials/` 提供给容器，但不会进入 git 提交与 docker 构建。

#### 4. 设置 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量

把 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量设为 JSON 文件的**完整路径**：

- **.env**（供 docker compose 使用）：

    ```env
    GOOGLE_APPLICATION_CREDENTIALS=/privatecredentials/service-account-key.json
    ```

- **类 Unix 系统**：

    ```bash
    export GOOGLE_APPLICATION_CREDENTIALS=/path/to/your/project/privatecredentials/service-account-key.json
    ```

- **Windows**：

    ```cmd
    set GOOGLE_APPLICATION_CREDENTIALS=C:\path\to\your\project\privatecredentials\service-account-key.json
    ```

#### 5. 保护你的凭证

- 确认该 JSON 文件已被 `.gitignore` 覆盖（放在提供的 `privatecredentials/` 目录里就已被覆盖）：

  ```text
  service-account-key.json
  ```

- **请对这个文件保密**，因为它授予了对你的 Google Cloud 资源的访问权限，可能导致**未授权使用**或产生费用。

### 验证配置

用以下命令测试凭证：

  ```bash
  gcloud auth activate-service-account --key-file=/path/to/your/service-account-key.json
  gcloud auth list
  ```

  你的服务账号应当显示为 active。

### 生产环境提示

这套配置适合开发环境。生产环境请考虑更安全的方案，部分方案列在[基于文件的凭证](05-基于文件的凭证管理.md)页面。
